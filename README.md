Trabalho_Site
📌 Descrição

Este repositório contém o desenvolvimento de um site funcional, criado como parte de um trabalho acadêmico. O projeto visa aplicar conceitos de desenvolvimento web, incluindo estruturação de banco de dados, criação de interfaces interativas e integração de funcionalidades dinâmicas.

🛠️ Funcionalidades

O site implementa as seguintes funcionalidades:

Cadastro de Fornecedores: Permite o registro de novos fornecedores no sistema.

Cadastro de Produtos: Facilita o registro de novos produtos disponíveis.

Edição de Fornecedores e Produtos: Oferece a capacidade de editar informações existentes.

Exclusão de Itens: Permite a remoção de fornecedores ou produtos do sistema.

Relatórios: Gera relatórios baseados nos dados cadastrados.

🧪 Tecnologias Utilizadas

PHP: Linguagem de programação server-side para processamento de dados.

MySQL: Banco de dados relacional para armazenamento de informações.

HTML/CSS: Estruturação e estilização da interface do usuário.

JavaScript: Interatividade no lado do cliente.

XAMPP: Ambiente de desenvolvimento local para PHP e MySQL.

📁 Estrutura do Repositório

css/: Contém os arquivos de estilo (CSS) do projeto.

img/: Armazena as imagens utilizadas no site.

xampp/: Inclui arquivos específicos para o ambiente XAMPP.

aplicativo.php: Arquivo PHP principal do aplicativo.

cadastrar_fornecedor.php: Formulário para cadastro de fornecedores.

cadastrar_produto.php: Formulário para cadastro de produtos.

cadastro.php: Página de cadastro geral.

conexao.php: Arquivo de conexão com o banco de dados.

editar_fornecedores.php: Página para edição de fornecedores.

editar_produto.php: Página para edição de produtos.

excluir.php: Arquivo para exclusão de itens.

fornecedores.php: Lista de fornecedores cadastrados.

index.php: Página inicial do site.

log.php: Arquivo de log do sistema.

relatorios.php: Página para visualização de relatórios.

🚀 Como Executar

Clone este repositório em sua máquina local.

Instale o XAMPP ou outro servidor local de sua preferência.

Coloque o diretório clonado na pasta htdocs do XAMPP.

Inicie o servidor Apache e MySQL através do painel de controle do XAMPP.

Acesse http://localhost/Trabalho_Site/ em seu navegador para visualizar o site.
